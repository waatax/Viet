## v2.19.0 單字閃卡重做、Top 1,000 詞庫校正與全單元內容擴充

- **Top 1,000 高頻字逐條人工校對**：原詞庫釋義多取自古漢語或方言義項（如 đang＝「次 / 鼎」、xe＝「搓 / 紡」、năm＝「春秋 / 寒暑」），例句多為片語或套版假句。現已改為現代台灣華語常用義、994 句包含該字的完整例句、詞性與 167 則「易錯提醒」；漢越音同音誤配（anh＝英、ai＝哀、xa＝車）一併修正，6 筆字母雜訊（c、m、i…）不再出現。Top 3,000 以上的階層移除套版假例句與英文佔位字，並標示「尚未逐條校對」。
- **磨耳朵音檔重錄**：Top 1,000 的 20 個「越中 ×3」音檔改用校正後的中文釋義重新錄製。
- **閃卡學習流程重做（卡片優先）**：開啟頁面即可「開始學習」，桌機與手機都不用往下捲；每回合先複習到期字、再穿插新字；答錯的卡片 3 張後換題型再考一次；評分按鈕顯示真正會排定的下次複習時間；回合結束提供答對率、需加強清單與「立刻再練錯的字」。
- **五種提取練習、由易到難**：翻卡回想、看字選義、聽音選義、看中選越（干擾選項為聲調／字形相近字）、聽寫拼字（可不打聲調）。「智慧混合」依熟練度自動切換題型。
- **答錯一定說明原因**：系統分辨聲調雙胞胎、母音符號（u／ư）、拼字相近或同詞性混淆，逐音節指出你選的聲調與正確聲調，並可一鍵比較兩個字的發音。
- **瀏覽與連播**：字典式清單（搜尋、學習狀態、詞性篩選、收藏），保留中→越、越→中、純越、越中 ×3 連續播放。
- **各單元內容至少 +10%**（以 2351f42 為基準，`npm run test:flashcards` 自動核對 22 項清單）：闖關題 232→264、實用短句 805→891、易混字 27→30、語法練習 20→23、測驗 30→33、漢越字根 67→74、急救卡 21→24、7 天速成短句 35→42、主題字卡 70→77、政經術語 22→25、情境研經新增「傳統市場」等；新增題目皆附答錯解說，並補齊 2,000 多個離線語音。
- **修正**：主題字卡評分時呼叫不存在的 `srsEngine.recordReview` 而報錯；舊閃卡在「待複習」篩選下評分會跳過下一張、自測模式的 1–4 鍵誤觸評分、易混字模式按 N／P 會操作到隱藏的字卡、深色模式答題回饋文字對比不足。

## 🚀 快速開始 (Quick Start)

### 1. 安裝相依套件
```bash
git clone https://github.com/waatax/Viet.git
cd Viet
npm install
```

### 2. 啟動本地開發伺服器
```bash
npm run dev
```
瀏覽器開啟 `http://localhost:5173/Viet/` 即可即時預覽與除錯。

### 3. 編譯正式生產版本
```bash
npm run build
```
編譯產物將生成於 `dist/` 目錄中。

### 4. 部署至 GitHub Pages
先將修改提交至 main 或 master，再執行：
```bash
npm run deploy
```
此指令先執行會話檢查與建置，再推送來源碼；GitHub Actions 負責發布，不會強制覆寫 gh-pages 分支。發布後自動比對線上的 release.json 與提交版本。也可手動確認：
```bash
npm run verify:pages
```
頁首、頁尾版本來自同一個版本設定；頁尾「版本紀錄」提供正式版的提交編號與建置時間。

### 5. 新增或修改情境對話後重建語音
對話句子有增修時，先匯出需要配音的句子，再以 edge-tts 生成中文翻譯語音（及缺漏的越文語音）：
```bash
node scripts/extract_dialogue_texts.mjs
python scripts/generate_dialogue_audio.py
```
中文語音輸出至 `public/audio/zh/`，對照表為 `src/data/audioManifestZh.json`；已存在的檔案會自動略過。範圍涵蓋所有情境對話、情境字彙、五階段會話，以及「情境深度研經」卡片會朗讀的越文例句與口語擴展。

> 需要 `edge-tts` 7.3.1 以上（`pip install -U edge-tts`）；舊版會被微軟語音端點以 HTTP 403 拒絕。
