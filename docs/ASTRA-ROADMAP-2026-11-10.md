# ASTRA 越南語學習體驗深化路線圖

日期：2026-11-10。對象：以繁體中文為主要說明語言、希望能在越南日常生活與職場實際溝通的學習者。

本文件是實作前的程式與資料審查及驗收設計。已讀取現有程式，並用 esbuild 在記憶體內載入正式資料計算基線；未以 README 的宣傳數字代替資料。路線圖本身不表示新增功能已完成，也不表示已完成真實裝置聽測。從工作區逐層到磁碟根目錄未發現適用的 AGENTS.md。

## 一、結論與本次產品目標

現有網站已具備相當完整的教學資產：三階會話播放、知識圖解、題目解說、錯題間隔複習及中斷續學。本次應把「知道去哪裡開始 → 看懂一個要點 → 聽懂 → 遮字回想 → 回應情境 → 得到錯因 → 明日再練」串成清楚的路徑，並增加真正可教、可測、可播放的新內容。

本次建議交付四個使用者可看見的成果：

1. 首頁提供可立即開始的短時練習路徑，並顯示下一步與到期複習；保留現有三視角導覽。
2. 每個既有知識模組增加一個具例句、中文解釋、易錯提醒、圖解及練習連結的知識點；每模組再提供一個有獨立情境問題的引導練習。保留現有 232 道 Quest 題。
3. 引導練習將聽懂、回想、開口與情境遷移接起來，加入自行核對的 1／3／7 日複習及徽章；音訊能播放，也能清楚知道哪些資源可保存成 MP3。
4. 手機直式可單手完成一輪練習，平板和桌機提高資訊並排的效率；發布後核對正式網站版本與實際入口。

## 三、七個面向、七輪依序深化檢討

七個面向：A 華語學習者教學、B 內容與正確性、C MP3 與聽說、D 學習與強化閉環、E 會話及遊戲評量、F 圖表與響應式介面、G 工程與發布。

以下各輪以前一輪的決策為輸入：盤點缺口 → 定義任務 → 跨功能整合 → 邊界檢討 → 減少負擔 → 驗證失敗情境 → 發布取捨。共 49 項具體發現或修正，不把同一句建議重複列為七次審查。

## 四、具體新增內容配置

每個新增點以「應用」為主，避免所有第十點因既有 `Math.floor(i / 3)` 邏輯自動成為進階。若沿用自動邏輯，需明確調整或補上逐點 tier。
