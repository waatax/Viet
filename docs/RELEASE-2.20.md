## 已執行驗證

- `npm run test:knowledge`：通過。20/20 教學頁、200 張隱藏答案卡、200 圖解，教學頁稽核 160/160；原 Quest、閃卡、詞彙與前版內容增量測試均保留。
- `npm run test:workspace`：通過。React 元件實際點擊完整四步，包含正常完成、錯答、提示收起防誤算、儲存不可用與首頁入口；另外驗證 1／3／7 日與提前練習不跳級。
- `npm run test:dialogue`：通過。2161 行、越中音檔缺漏 0；175 段雙模式、錯誤恢復、停止與鎖屏計時器模擬測試。
- `npm run test:quality`：通過。3885 個音檔（vi 1968、zh 1917），無不可讀、格式、靜音、時長、不同文字共用檔案、雙重聲調或繁體用字異常。
- `npm run test:audio`：檔案完整性檢查通過；深層稽核初次指出 28 缺檔，已補齊並重跑 `node scripts/deep_audio_audit_v2.mjs`，缺檔 0。原稽核只列印未失敗的行為已修正。
- `npm run build`：正式建置驗證。音訊 manifest 與大型字彙資料仍有 Vite chunk 大小提示，屬既有資料架構，未偽稱已完成全站載入效能重構。
- `git diff --check`：無格式錯誤。

## 驗證界線與後續

依要求不開本機預覽；手機／平板／桌機 CSS 與焦點路徑已實作，但未做實際尺寸視覺驗收。React 模擬測試不代表 iOS／Android 真機背景播放測試。音檔機械稽核不等於母語者逐句聽審。口說採自行核對，沒有自動發音評分。複習紀錄只在本機瀏覽器，未提供跨裝置同步。

正式版發布以 `release.json` 的版本與提交 SHA 比對為準；執行 `npm run verify:pages` 可再核對。站點：[Viet Learning Hub](https://waatax.github.io/Viet/)。
